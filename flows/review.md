# C. 복습 (`/study review`)

SKILL.md 의 분기(또는 A2)에서 넘어온 흐름. 진도 파일을 다루기 전에 progress-rules.md 를 Read 한다 ("규칙 §n"). 문항은 SKILL.md [문항 규칙]대로 낸다.

자료 없이 복습일이 도래한 개념만 다룬다. 학습 세션 수는 늘리지 않는다.

## C1 — 대상 고르기

1. 복습할 주제를 찾는다:
   ```bash
   node C:/Users/sgosp/.claude/skills/study/scripts/progress.js due
   ```
   "복습할 개념 없음"이면 `index.md` 의 가장 이른 `다음 복습`을 알려 주고 종료.
2. 여러 주제면 AskUserQuestion 으로 고르게 한다 (전체 / 주제별).
3. 고른 주제의 순서를 받는다 — 스크립트가 `확신 오류` → 오개념 → `설명 누락` → 가장 오래 밀린 순으로 정렬하고, 같은 묶음이 연달아 나오지 않게 섞는다:
   ```bash
   node C:/Users/sgosp/.claude/skills/study/scripts/progress.js due <slug>
   ```
   topic 파일도 Read 한다 (오개념·설명 누락 메모를 보고 문항을 고르기 위해).
4. 위에서부터 한 번에 최대 5개. 남은 것은 요약에 "남은 복습 n개"로 알리고, 학습자가 원하면 5개씩 더 한다.
   - A2 "빠르게 2개"로 들어왔으면 최대 2개.
5. 복습할 개념이 5개 미만이고 `나중에 볼 목록`에 `확인 전` 개념이 있으면 (스크립트 출력 마지막 줄), 빈자리를 그 개념으로 채울지 AskUserQuestion 으로 묻는다. 채우면 flows/done.md B2 의 학습 중·새 개념 방식(설명해보기 + 퀴즈 1문항)으로 확인한다.

## C2 — 복습 진행

- 학습 중 개념: **설명해보기 + 퀴즈 1문항**.
- 익힘·정착 개념: **퀴즈 1문항**.
- 압축 줄: compression.md 를 Read 하고, 구성원 하나를 골라 **퀴즈 1문항**.
- 스크립트 출력의 `왜 문항` 은 "왜 / 무엇과 어떻게 연결되나" 문항으로 내라는 뜻이다 (문항 규칙 1).
- 결과는 규칙 §2 복습 전이 표대로 처리한다. 압축 줄을 틀리면 compression.md 펼치기를 수행한다.

## C3 — 기록과 요약

1. 개념마다 flows/done.md B3 1번과 같은 방식으로 반영한다 (메모 Edit → `apply`).
2. `최근 로그`에 복습 줄 추가 (`- <날짜> — 복습 — <n>개 중 <m>개 통과, <상태 변화 요약>` — `stats` 가 이 형식으로 통과율을 계산한다), 학습 패턴 갱신 (규칙 §6).
3. 압축 확인 — 한 묶음에 정착 개념이 3개 이상이면 compression.md 를 따른다.
4. index 를 맞춘다: `progress.js sync-index <slug> --studied`.
5. 요약:
   ```
   ## 복습 결과 — <주제>
   - 통과: n개 (정착으로 올라감: … )
   - 내려감: … (이유: 실수 / 오개념)
   - 압축됨 / 펼쳐짐: … (있을 때만)
   - 남은 복습: n개
   - 다음 복습: <날짜>
   ```

끝나면 SKILL.md [진도 저장].
