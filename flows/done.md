# B. 진도 갱신 (`/study done`)

SKILL.md 의 분기에서 넘어온 흐름. 진도 파일을 다루기 전에 progress-rules.md 를 Read 한다 ("규칙 §n"). 문항은 SKILL.md [문항 규칙]대로 낸다.

## B1 — 대상 확인

1. `index.md` 를 Read. 진행 중 계획이 있는 주제가 여럿이면 AskUserQuestion 으로 고르게 한다. 없으면 주제를 묻는다.
2. 해당 `topics/<slug>.md` 를 Read.
3. 공부한 범위를 확인한다 — `세션 메모`가 있으면 "세션 메모 기준으로 <단계·개념>까지 맞죠?"로 확인하고, 없으면 "어디까지 공부했나요?"를 묻는다. 학습자는 계획의 단계 번호로 답하거나 배운 개념을 자유롭게 말해도 된다.
4. **공부한 범위 안의** 개념만 확인한다. 범위 밖에서 복습일이 도래한 개념은 다루지 않고 B4 요약에서 `/study review` 를 안내한다. 확인할 개념:
   - 대상: 학습 중 개념 + 처음 나온 새 개념 + 범위에 나온 `나중에 볼 목록`의 `확인 전` 개념 (새 개념은 기존 묶음 이름을 재사용해 묶음을 정하고, 지식 종류를 붙이고, 분명하면 `선수:`도 적는다). 새 개념은 규칙 §2 "새 개념으로 기록하는 기준"을 만족하는 것만 (한 줄 언급은 제외).
   - 익힘·정착·압축 개념은 복습일이 도래한 것만 포함하고, 나머지는 건너뛴다 (규칙 §2: 단계 건너뛰기 방지).
   - 최대 5개. 넘으면 오개념·설명 누락이 있는 개념을 우선하고, 확인하지 못한 새 개념은 `나중에 볼 목록`에 `배움 <날짜> · 확인 전`으로 기록한다 (학습 중에 넣지 않음, 규칙 §2).

## B2 — 설명해보기 + 퀴즈 (개념마다)

학습 중·새 개념:
1. **설명해보기**: "<개념>을 자기 말로 설명해 보세요." → 빠진 부분·틀린 부분을 구체적으로 짚는다. 정답을 길게 다시 강의하지 말고 핵심 교정만. 학습자의 설명을 규칙 §1 SOLO 표로 판정해 깊이를 정한다 (학습자가 말한 것만 인정 — 문항 규칙 4).
2. **퀴즈 1문항** (학습자 요청 — 시간 절약): 설명에서 빠졌거나 틀린 지점이 있으면 그 지점으로 낸다. 형식은 문항 규칙 1 (개념·절차는 객관식 금지).
   - `세션 메모`에 그 개념의 놓친 것 확인 '확실'이 있으면 그것을 퀴즈로 인정하고 설명해보기만 한다.
3. **판정**: 규칙 §2 "`/study done` 판정" 표대로.

복습일이 도래한 익힘·정착·압축 개념: 규칙 §2 복습 전이 표대로 퀴즈 1문항 (압축 줄이 틀리면 compression.md 펼치기).

## B3 — 기록

1. 개념마다 판정을 반영한다 (규칙 §7 순서):
   - 먼저 Edit: 오개념 메모(`오개념[<범주>]: …`), `설명 누락: …` 추가·삭제, 새 개념 줄 추가 (`학습 중` 섹션에 묶음·지식 종류·깊이까지).
   - 그다음 실행:
     ```bash
     node C:/Users/sgosp/.claude/skills/study/scripts/progress.js apply <slug> "<개념>" <확실|애매|찍음|틀림|오개념> [--explained] [--sure] [--depth <깊이>]
     ```
     `--explained` = 설명해보기 통과(틀린 내용 없음), `--sure` = '확실'로 답하고 틀림, `--depth` = SOLO 로 판정한 깊이. 스크립트가 계수·간격·다음·표시·섹션 이동·`나중에 볼 목록` 정리·index 를 맞춘다.
2. `진행 중 계획`의 체크박스와 `n/N단계` 갱신. 마지막 단계까지 끝났으면 로그에 "<자료명> 완주"를 남기고, 계획 섹션을 `- 없음 (최근 완주: <자료명>, <날짜>)` 로 바꾼다 (수준 올림 확인은 7번에서).
3. `최근 로그`에 한 줄 추가 (규칙 §6). 세션 메모에 코드 읽기 결과가 있으면 끝에 `코드 읽기 m/n` 을 붙인다. 10줄 초과 시 오래된 줄은 archive 로.
4. `마지막 진단` 옆 학습 세션 수 +1.
5. **학습 패턴 갱신** (규칙 §6).
6. **압축 확인** — 한 묶음에 정착 개념이 3개 이상이면 compression.md 를 Read 하고 따른다.
7. **영역별 실력 확인**: 규칙 §4 영역 올림 조건이면 AskUserQuestion 으로 제안, 승인 시에만 변경.
8. `세션 메모`를 `- 없음` 으로 비운다 (내용은 3번 로그 한 줄에 요약됨).
9. index 를 맞춘다: `progress.js sync-index <slug> --studied` (마지막 학습 = 오늘).

## B4 — 요약

```
## 오늘 학습 결과 — <주제>
- 익힘으로 올라감: ... (설명 누락 남음: … — 복습에서 다시 물음, 있을 때만)
- 아직 학습 중: ... (오개념: … / 확신 낮음: …)
- 깊이 변화: ... (있을 때만, 예: static 초기화 표면 → 심층)
- 확신 오류: ... (있을 때만)
- 압축됨: ... (있을 때만)
- 나중에 볼 목록으로: ... (확인 못 한 개념, 있을 때만)
- 계획 진행: n/N단계
- 다음 복습: <가장 이른 날짜> — <개념 n개>
- 다음에 할 일: <다음 단계>
```

끝나면 SKILL.md [진도 저장].
